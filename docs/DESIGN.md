# 《灯芯深渊》Wickdeep 设计文档

俯视角像素风动作 Roguelite。单机，一局约 25 分钟。所有美术和声音都由 `tools/assetgen/` 里的 Python 脚本生成。

## 故事

地底修道院"深渊"里最后一簇圣火快要熄灭。你是年轻的守灯人，提着一盏住着火灵"灯芯"的提灯往下走，要在第五层击败吞噬光的"熄灯者"，重新点燃圣火。

## 一局的结构

| 深度 | 区域 | 内容 |
|---|---|---|
| 1 | 苔石回廊 | 普通楼层 |
| 2 | 苔石回廊 | 普通楼层，出口是首领"苔母" |
| 3 | 骨灰书库 | 普通楼层 |
| 4 | 骨灰书库 | 普通楼层 |
| 5 | 熄灭圣所 | 几个房间之后是最终首领"熄灯者" |

每层结束后进入**营地**：篝火让你恢复 2 点生命（每次光顾一次）；火灵灯芯会点评你这一层的表现，可以和它聊天；商人"秤婆"卖遗物和灯油，可以和她砍价。到达营地时自动存档，可以从标题画面"继续"。

## 楼层

- 地牢由程序生成，同一个种子生成同一张图（以后联机时双方可以用种子生成同一个地牢）。
- 房间排在 5×5 的宏观网格上，相邻房间用 3 格宽的走廊连接。房间种类：
  - **起点**：安全。
  - **战斗**：进入后门锁上，敌人分 1～2 波出现，出现前地面先有预警光圈；清完开门，掉落余烬。
  - **宝藏**：祭坛，三选一遗物。
  - **圣烛台**：恢复 2 点生命，每层一次。
  - **出口**：楼梯；第 2、5 层是首领房。
- 房间内部有若干种障碍布局（柱阵、中央石台、散落碎石），生成后用洪水填充检查所有门都能互相到达。

## 玩家数值（初始）

- 生命 6（界面显示为 3 个灯火图标，每个 2 点，可显示半格）。受击后无敌 1 秒。
- 余烬弹：伤害 10，间隔 0.25 秒，速度 280，射程 220。
- 冲刺：0.16 秒、约 48 像素，冷却 0.75 秒，无敌 0.22 秒。
- 爆燃：造成伤害会充能（伤害 × 0.25，满 100），释放后半径 90 内造成 40 伤害、击退并清除敌方子弹。

## 敌人

| 敌人 | 行为 | 生命 |
|---|---|---|
| 灰泥史莱姆 | 蓄力后跳向玩家 | 22 |
| 煤灰蝙蝠 | 不规则飞行，俯冲 | 14 |
| 骨弓手 | 保持距离，瞄准线预警后射箭 | 26 |
| 孢子囊 | 固定炮台，三连散射 | 40 |
| 幽火术士 | 漂移、闪现，八方向慢速弹幕 | 34 |
| 墓甲骑士 | 慢走，闪烁预警后直线冲锋，撞墙会晕 | 75 |
| 小影 | 首领召唤的快速小怪 | 10 |

敌人生命按深度提升（每层 +22%），第 3 层起每个房间额外多刷一些敌人。每个房间按"预算点数"抽取敌人组合，预算随深度增长。

## 首领

- **苔母**（第 2 层，生命 650）：巨型史莱姆。跳跃落地放冲击弹环；生命降到 2/3 和 1/3 时各分裂出一批小史莱姆；最后阶段连跳。
- **熄灯者**（第 5 层，生命 2400）：三阶段弹幕。
  1. 带缺口的弹环、瞄准三连射、"熄光波"（玩家光圈暂时缩小，同时召唤小影）。
  2. 螺旋弹幕、横穿场地的冲锋、召唤幽火术士。
  3. 狂暴：攻击更快，"蜡雨"（先出现预警圈，再落下蜡滴）。

## 遗物（25 种）

普通 / 稀有 / 传说三档。有的能叠加。效果包括：多重弹、伤害、射速、穿透、反弹、灼烧、追踪、射程、护盾、吸血、移速、冲刺伤害、拾取范围和余烬加成、死亡爆炸、环绕火灵、暴击、生命上限、爆燃充能、分裂弹、敌弹减速、诅咒型贪婪、狂野射速、受击自动爆燃、复活一次、熔核大弹。每件遗物的效果和数值都写在 `src/data/relics.gd` 的同一张表里；伤害和射速的加成先相加、乘数再相乘，结果与拾取顺序无关。

## 经济

- 敌人掉 1～3 余烬，清房奖励 5～10。
- 商店：遗物 45 / 75 / 120（普通 / 稀有 / 传说），灯油 25（回 2），大灯油 55（回满）。

## AI 角色（DeepSeek）

- 接口：DeepSeek 官方 OpenAI 兼容接口 `https://api.deepseek.com/chat/completions`，模型 `deepseek-flash`；在设置里可以改地址和模型。
- 请求关闭思考（`"thinking": {"type": "disabled"}`），并使用 JSON 输出（`response_format: json_object`），保证回复快、格式可解析。
- API Key 由玩家在"设置 → AI"里自己填写，存在本机 `user://settings.cfg`；也可以用环境变量 `DEEPSEEK_API_KEY`。Key 不打包进游戏。
- **灯芯**（火灵）：
  - 到达营地时，根据本层数据点评一句；
  - 可以自由聊天；
  - 死亡或通关时写一段墓志铭，并把一句"记忆"存进存档，下一局会提起。
- **秤婆**（商人）：自由砍价。模型返回 `{reply, mood_delta, price_multiplier, gift, memory}`，游戏对数值做限制：
  - 每句话价格最多变动 ±0.10，总范围 0.70～1.30；
  - 每次光顾最多送一次灯油；
  - 每次光顾最多说 6 句。

  即使提示词被注入，经济也不会被打穿。
- **没有 Key 或请求失败**：自动改用预设台词和预设砍价选项（夸货、砍价、讲故事、威胁），游戏完整可玩。

## 画面与声音

- 内部分辨率 640×360，整数倍放大，最近邻采样，16 像素图块。
- 地牢底色是暗色，靠玩家提灯、墙上火把和余烬弹照明（Light2D）；敌方子弹和特效不受光照影响，在暗处也看得清。
- 程序生成音效：射击、命中、死亡、受伤、冲刺、爆燃、拾取、开关门、界面等。
- 程序生成芯片音乐：标题 / 营地、地牢、圣所、首领，以及胜利和死亡的短乐句。

## 平衡测试

用自动游玩机器人测难度（不开无敌）：机器人会躲子弹、避开预警圈、在营地买东西，但躲避能力明显不如真人。调整后，机器人能稳定通过第 1 层并以满血进入第 2 层。数值调整记录：
- 史莱姆蓄力 0.32 → 0.42 秒、跳跃距离 95 → 80 像素、速度约 250 → 190 像素/秒（史莱姆一直是最大的伤害来源），蝙蝠俯冲预警 0.35 → 0.45 秒；
- 苔母生命 800 → 650，落地弹环更慢，吐弹 3 轮 → 2 轮，每次换阶段只分裂 2 只史莱姆；
- 首领层保证有一个圣烛台（地图没生成就放在起点房间）；
- 营地篝火回 2 点生命；
- 后期太容易（机器人带着 13 件遗物满血通关），所以敌人生命成长调到每层 +22%，第 3 层起多刷怪，商店遗物价格每层 +12%，熄灯者生命 2400。

## 手感

屏幕震动、命中停顿、受击闪白、击退、粒子、伤害数字、冲刺残影、相机朝准星方向偏移。

## 存档

- `user://save.json`：总局数、胜场、最深到达、总击杀、秤婆好感与记忆、灯芯的记忆、图鉴。
- `user://run.json`：到达营地时自动保存的本局状态，用来"继续"。
- 存档先写临时文件再替换，写到一半断电也不会留下损坏的存档。
- 带测试开关启动时（单元测试、机器人、截图），存档改写到 `user://sandbox/`，不碰真实进度。

## 以后的联机

- 输入抽象为 `PlayerInput`（键鼠 / 手柄 / 机器人），以后可以接网络输入；菜单里的选择抽象为 `Pilot`（真人 / 机器人）。
- 地牢生成只依赖种子。
- 联机方案见上一轮的推荐：服务器权威，WebSocket 走 443。
